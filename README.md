# LUMS Academic Knowledge Assistant (RAG System)

A production-ready Retrieval-Augmented Generation (RAG) application that answers student questions about LUMS using official university documents.

## 📋 Overview

This system provides an intelligent assistant that can answer questions about LUMS policies, courses, and schedules by retrieving information from:
- LUMS Student Handbook (PDF)
- Course Memos (Excel files)
- Course Schedules (Excel files)
